# Google Colab Usage Guide

1. Upload the notebook you want to run to Google Colab.
2. Ensure the runtime is Python 3.
3. Run the first code cell to install dependencies.
4. Continue running all cells in order from top to bottom.
5. For CNN and CIFAR-10 experiments, prefer a GPU runtime.
6. Keep the notebook connected to the internet for package install and dataset downloads.
7. If a matching dataset is not available (for example CIFAR-10), use the notebook's error message to determine whether the issue is network access or runtime capacity.

Note: Every notebook is designed to be independent from a fresh runtime and includes its own installation cell.
