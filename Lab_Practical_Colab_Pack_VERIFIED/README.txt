LAB PRACTICAL COLAB PACK
========================

Contains experiment-wise Python notebooks for:
1. 23IT039 Data Science Laboratory (9 folders)
2. 23IT040 Deep Learning Laboratory (11 folders)

HOW TO USE
----------
1. Extract this ZIP file.
2. Open https://colab.research.google.com/
3. Choose File > Upload notebook.
4. Upload the required .ipynb file from the relevant experiment folder.
5. Run cells from top to bottom using Shift+Enter.
6. Installation cells are included where needed.

NOTES
-----
- Most notebooks use built-in/sample datasets and download data when first run.
- Internet access is required for downloading datasets and packages.
- Deep-learning notebooks use small epoch counts for faster practice. For full lab runs,
  increase epochs if required by your faculty.
- Basemap is optional and can be difficult to install in a fresh Colab runtime; its notebook
  includes an installation attempt and a Matplotlib fallback.
- See VALIDATION_REPORT.txt for exactly what was tested and what could not be run here.
- Accuracy values vary by runtime, random initialisation, and training duration.
- Dataset columns in a faculty-provided CSV may differ; update filenames/column names as needed.
